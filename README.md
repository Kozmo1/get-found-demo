# Get Found demos

Static brochure sites for Get Found outreach. No build step — GitHub Pages serves the HTML as-is.

## Bakery — Hearth & Crumb

Neighbourhood bakery / cafe brochure (New Hamburg vibe).

- Local: open `index.html`
- Live: [https://kozmo1.github.io/get-found-demo/](https://kozmo1.github.io/get-found-demo/)

## Salon — Studio Lumen

High-end nails / lashes / brows / waxing brochure (Elora vibe). Separate visual language from the bakery demo.

- Local: open `salon/index.html`
- Live: [https://kozmo1.github.io/get-found-demo/salon/](https://kozmo1.github.io/get-found-demo/salon/)

After merge, GitHub Pages publishes from `main`. The salon demo is at the `/salon/` path on the same Pages site — it does not replace the bakery home.
