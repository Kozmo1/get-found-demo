# Get Found demos

Static brochure sites for Get Found outreach. No build step — GitHub Pages serves the HTML as-is.

## Bakery — Hearth & Crumb

Neighbourhood bakery / cafe brochure (New Hamburg vibe).

- Local: open `index.html`
- Live: [https://kozmo1.github.io/get-found-demo/](https://kozmo1.github.io/get-found-demo/)

## Salon — Studio Lumen

High-end nails / lashes / brows / waxing brochure (Elora vibe). Separate visual language from the bakery demo.

- Local: open `salon/index.html`
- Live: [https://kozmo1.github.io/get-found-demo/salon/](https://kozmo1.github.io/get-found-demo/salon/)

## Florist — Atelier Blooms

Romantic florist brochure (Fergus vibe). Owned storefront look — the wire catalog can stay the backend. Distinct from both bakery and salon.

- Local: open `florist/index.html`
- Live: [https://kozmo1.github.io/get-found-demo/florist/](https://kozmo1.github.io/get-found-demo/florist/)

## Trades — Summit Mechanical

Contractor brochure (KW / Wilmot vibe): plumbing, electrical, reno. Bold navy/charcoal — not the salon or florist look. Send trades prospects straight to this URL.

- Local: open `trades/index.html`
- Live: [https://kozmo1.github.io/get-found-demo/trades/](https://kozmo1.github.io/get-found-demo/trades/)
